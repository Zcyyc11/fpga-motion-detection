# fpga-motion-detection

> 2026 全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新设计赛道（AMD）
> 赛道 **3.3 自主选题 · 初级组** ｜ 团队 **GGBOND** ｜ 大连理工大学

**作品名称：《基于 FPGA 的运动目标检测》**

基于 **PYNQ-Z2（Zynq-7020）** 的实时运动目标检测系统：HDMI 采集视频流 → **PL 端流水线**完成灰度化、帧间差分、阈值分割、形态学滤波 → **实时计算运动区域质心** → HDMI 输出叠加标记框；并**对比不同缓存方案下的 LUT / BRAM 占用与时序裕量（WNS）**。

---

## 1. 目录结构

采用**官方指南 §3.3.5.4 推荐目录结构**（未做改造，无需目录对照说明）：

| 目录 | 放什么 |
|---|---|
| `src/` | 设计源码：`rtl/` 自研 Verilog ｜ `hls/` HLS 算子 ｜ `ps/` PS 侧软件（PYNQ Python / notebook） |
| `sim/` | 仿真脚本与结果：`tb/` testbench ｜ `wave/` 波形与仿真输出图 |
| `build/` | **可复现构建脚本** `scripts/`（Vivado tcl）＋ 综合实现报告 `reports/`（LUT/FF/BRAM/DSP、WNS） |
| `board/` | 上板工程与实测：`overlay/`（`.bit`+`.hwh`）｜ `logs/` 实测日志 ｜ 运行脚本 |
| `data/` | 测试数据与参考结果：`golden/` 黄金参考 ｜ `captures/` 采集素材 |
| `skill/` | **技能包**（含 `README.md`，写明适用范围 / 使用方法 / 失效条件） |
| `report/` | **设计报告**＋`llm_log/` 大模型协作记录 |

## 2. 环境要求

| 项 | 版本 |
|---|---|
| 开发板 | PYNQ-Z2（XC7Z020-1CLG400C），512 MB DDR3 |
| 开发工具 | **Vivado / Vitis 2026.1** |
| 板卡运行环境 | PYNQ-Z2 官方镜像 **v3.1.1**（Python 3.x + Jupyter） |
| 工作分辨率 | **720p**（1080p 超出 Z2 的 HDMI 规范能力） |

> ⚠️ **镜像与工具版本错位**：镜像 v3.1.1 的 overlay 由 Vivado 2024.1 构建，与本工程 2026.1 不同。
> 加载时须 `Overlay("xxx.bit", ignore_version=True)` 跳过 HWH 版本校验，本工程所有 notebook 已按此写法。
