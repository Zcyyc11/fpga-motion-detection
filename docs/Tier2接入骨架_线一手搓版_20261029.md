## 一、当前顶层设计里已经留好的接口（实测，非凭记忆）

| 位置 | 现有钩子 | 现状 |
|---|---|---|
| `src/rtl/board/board_top.v` | 时钟 = `sys_clk` 125MHz(H16) 来自以太网 PHY → MMCM → 74.25/200MHz | **时钟坑根源**：不插网线 → PHY 停 CLK125 → 黑屏 |
| `src/rtl/board/board_top.v:196` | `md_pipeline .INCLUDE_PS(0)` | PS/AXI 口当前全部悬空，UART 链无条件生效 |
| `src/rtl/md_pipeline.v:96-104` | `clk_axi` / `ps_en` / `ps_we` / `ps_addr[5:0]` / `ps_wdata` / `ps_rdata` | 6 位地址的 regs 瘦总线从接口，**已存在、待接 AXI-Lite 桥** |
| `src/rtl/md_pipeline.v:48` | `parameter MODE_BG` | 0=帧差 / 1=背景建模（编译期切）；运行时还能经 regs 0x14 切 |
| `src/rtl/md_pipeline.v:10` | 2×2 累加压缩（8→10bit 大像素）省 BRAM | 背景模型目前**放 BRAM**，1 帧就占 45%，ViBe N=20 要 940% → 必须搬 DDR |

**判定**：顶层接入点全齐，不用改架构，只加"桥 + DMA + DDR 路径"。

## 三、BD（Block Design）骨架图

```
            ┌─────────────────── Zynq PS7 (Processing System) ───────────────────┐
            │  FCLK_CLK0 (→ PL 像素/AXI 时钟, 替 PHY125 治黑屏)                    │
            │  FCLK_CLK1 (→ VDMA/AXI 时钟)                                        │
            │  GP0 (AXI-Lite Master) ──► AXI-Lite 桥 ──► md_pipeline.ps_* 寄存器   │
            │  HP0 (AXI-MM, 64bit, 高吞吐) ──► AXI VDMA (S2MM + MM2S)             │
            └───────────────────────────────┬─────────────────────────────────────┘
                                             │ AXI-MM (经 HP0 进 DDR 控制器)
            ┌────────────────────────────────┼────────────────────────────────────┐
            │  DDR3 控制器 (PS 内)  ◄─────────┘   背景模型 + 帧缓冲 住这里          │
            └─────────────────────────────────────────────────────────────────────┘
                  ▲ S2MM 写帧 / MM2S 读背景样本
            ┌─────┴─────────── PL 侧视频流 ────────────┐
   HDMI IN → dvi2rgb → hdmi_in_ctrl → gray_conv ─┐
                                                    ▼
                                    md_pipeline (检测核心, 改从 DDR 取背景)
                                                    │
                                    rgb2dvi → HDMI OUT (红框叠加不变)
```

**关键约束（来自前期排雷，别再踩）**：
- GP0 不接时钟 → BD 报 41-758；FCLK 必须从 PS 引出到顶层再用，否则 DRC NSTD-1/UCIO-1 拒 bitgen（应在 BD 内直连）。
- VDMA 走 HP0 端口（不是 GP），背景模型大流量必须 HP 高带宽。
- dvi2rgb RefClk 仍需 200MHz（独立 MMCM，不蹭像素时钟 VCO）。

## 五、验收门（Tier2 算"整完"的硬判据）

1. 拔掉 RJ45 网线 → 屏仍出图（时钟坑根治，FCLK 生效）。
2. VDMA 通道起流：S2MM 写 DDR 帧率 ≥ 60fps@720p 无丢帧；MM2S 回读背景样本正确。
3. 背景模型确实在 DDR（BRAM 占用回落到 <10%，非 BRAM 枷锁）。
4. 算法从帧差(L0)升到 ViBe/GMM(L2)：静止背景不再误报、运动目标框稳；用 OpenCV(Tier3) 黄金参考对标，F1 较当前帧差有明显提升（目标 ≥0.6 宏平均）。
5. 另一人跑 tb 互验签字（改接口前群内确认）。
