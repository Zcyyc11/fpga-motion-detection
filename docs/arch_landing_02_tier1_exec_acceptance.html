三、上板验 Tier1 可直接用的 Checklist

  1. 准备物料：PYNQ 镜像 SD 卡、12V 3A 电源（J9）、Micro-USB（烧录/串口）、HDMI 线、示波器 / 逻辑分析仪、采集卡。
  2. 核对 bit：烧录前 Get-FileHash 核对 tier1/board_top_tier1.bit = e4f1e25c0d3a71b6f126fa7e2f7fff248a9e4b267c932b641a2016aaf46d6559。
  3. SD 启动：插好镜像 SD 卡，上电，串口 115200 看能否进 PYNQ（自动登录）。
  4. 测时钟：启动后读时钟状态 / 用仪器测 FCLK_CLK0 引脚，确认 125MHz 有效。
  5. 送视频：电脑 Win+P 复制，输出必须 1280×720；HDMI OUT（J11）接采集卡，看是否出图。
  6. 拔网线测试（核心）：拔掉 RJ45 网线，确认仍稳定出图、不黑屏。
  7. 记录回传：bit SHA + 照片/视频 + 串口启动日志 + FCLK 测量值 + HDMI 视频/截图 + 运行时长 + 验收结论。
回传四件套（给线一核对 SHA + 给徐一夫做效果复核输入）：bit SHA、HDMI 视频、原始串口流（raw_stream.bin + frames.jsonl）、验收汇总。物理板测归持板队员，线一只备清单 / 核对 / 解码说明。
