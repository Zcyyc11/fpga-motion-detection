章节定位：创新点章节对应评分"创新性"30 分。我们的创新不在"发明新 CV 算法"，而在工程层面的架构推理与资源约束下的务实落地——这正是评审看重的"为什么撞墙、怎么绕"。

一、创新点一：PS/PL 协同架构 + FCLK 根治时钟坑

  • 指出问题（有官方出处）：纯 PL 架构 125MHz 来自以太网 PHY（网口芯片），官方参考手册 v1.0 §5 铁证——RJ45 不 link 即 PHY 停 CLK125，导致 dvi2rgb 永久复位、整板黑屏。这是设计级硬约束。
  • 创新做法：引入 PS 的 FCLK 作为系统时钟源，彻底解耦"出图"与"网线"；并让 PS 接管 track / 告警 / 串口 / 在线调参，把利用率 0% 的 PS/DDR 用起来。
  • 价值：治本黑屏、为后续背景建模铺路，且符合 PYNQ 社区主流 HDMI 设计惯例。

二、创新点二：资源约束下的背景建模务实落地

  • 指出矛盾（有数据）：BRAM 4.9Mb 与标准 ViBe（N=20 需 46Mb，940%）的物理矛盾——这是 FPGA 跑背景建模的共性约束，非板子独有。
  • 务实路线：先用 MODE_BG=1 均值背景（零 BRAM 增量，把系统从 L0 帧差抬到 L2 思想层）；中长期用 VDMA+DDR 把背景模型放外部 DDR，解锁真 ViBe/GMM。
  • 诚实标注：算法血统来自 2cc2ic 开源（THRESH=70、2×2 累加压缩），我们在其基础上做资源约束下的落地与工程改造（非原始创新）。

三、创新点三：分层渐进验证与开源复用工程方法

  • 方法：Tier1/2/3 分期 = 借成熟开源块（PYNQ 社区 VDMA/DDR 多例实证）增量集成 + 逐层上板验，按依赖顺序控风险。
  • 强调：同板（PYNQ-Z2 / xc7z020）已有成熟开源方案与同芯片 ViBe 论文（2024《舰船电子工程》）。我们做的是"复用 + 自主集成 + 验证"，而非从零造轮子。
