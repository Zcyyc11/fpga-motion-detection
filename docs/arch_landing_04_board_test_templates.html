板测回传四件套模板

团队 GGBOND · 给持板队员的回传清单 · 线一（主城要）备 · 2026-10-28

用途：持板队员做完 Tier1 上板验后，按这四件套回传。线一核对 bit SHA、徐一夫拿串口流做效果复核。四件缺一不可，少一件线一无法判验、徐一夫无法复核。

四件套清单（要回传什么 / 格式 / 命名 / 用途）

件③ 串口流怎么采（命令，持板队员照抄）

接线：3.3V USB-TTL 的 RX ↔ 板子 PMOD A1（ja[0]/Y18），GND 共地（板载 MicroUSB 走 PS MIO，收不到 PL 串口）。
命令：python sim/line3/uart_receiver.py --port COMx --baud 115200 --duration 60 --out evidence/tier1
注意：目录 evidence/tier1 必须不存在（脚本会自建）；采集前用 tasklist | grep -i camera 确认 Windows 相机 App 已关（否则独占采集卡报 0xC00D3704）。
