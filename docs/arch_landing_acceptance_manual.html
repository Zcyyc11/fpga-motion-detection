步骤 2 · 板测-纯 PL 版（JTAG，作排障基线）

在候选包根目录（需 Vivado + JTAG 连目标板）：

vivado -mode batch -source pl/burn_candidate.tcl

该脚本 JTAG 加载 board_top_legacy.bit，参考时钟来自板上 H16（以太网 PHY）。此版拔网线会黑屏——这是已知设计约束，不是 bug，用来和 Tier1 版对比即可。

步骤 3 · 板测-Tier1 版（SD 启动 + 时钟坑判据）★核心

需要一张已能启动的 PYNQ-Z2 SD 卡。把候选包 tier1/ 目录拷到 SD 可读目录（保持 .bit 与 .hwh 同目录同名）。板上终端执行：

cd /home/xilinx/fpga_candidate/tier1
sudo python3 tier1_startup.py --bit board_top_tier1.bit \
    --sha256 e4f1e25c0d3a71b6f126fa7e2f7fff248a9e4b267c932b641a2016aaf46d6559 \
    --log board_startup_01.json

脚本会：先核 bit 哈希 → 下载 → 设时钟(FCLK0=125/FCLK1=100) → 写回读阈值/学习率/警戒线/模式。判据：拔掉网线也能加载出图 = 时钟坑治愈 ✓；不依赖网线是设计内建的。首次运行生成的新日志不能覆盖旧日志。先加载设参，再播测试视频。

步骤 4 · UART / HDMI 取证（回传四件套）

接线：USB-TTL 必须 3.3V，RX 接 PMOD A 第 1 脚 / Y18，GND 共地；串口 115200 / 8-N-1。别把板上 MicroUSB 的 PS 串口当这条 PL 输出。 HDMI 输入 J10、输出 J11，输入固定 1280×720。

PC 端（在候选包 pc/ 目录，把 COM7 换成实际端口，输出目录须不存在）：

python uart_receiver.py --port COM7 --baud 115200 --duration 60 \
    --out capture_01 --source board-unverified --save-images 0

该命令产出 raw_stream.bin + frames.jsonl + 接收汇总。回传四件套 = ①实际 bit SHA ②接线/JTAG 截图 ③HDMI 输入+输出原视频 ④raw_stream.bin + frames.jsonl + 接收日志 + 丢包统计。

红线警告（材料里不许瞎吹，韦博自己披露的）

  • 夜间场景仍有退步（nightVideos 后续段 Q4=0.224 < 旧帧差 0.402），不能宣称"所有场景都提升"。
