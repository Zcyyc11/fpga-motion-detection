# 效果定量量化 + 板子性能对标主流探讨（线一 · 2026-10-22）

> 定位：孙伟博的交接验收要求（bit 核对/烧录/HDMI/串口/回传/填模板）是**"能不能跑通"的流程及格线**；
> 评委真正看的是**效果（要数字）+ 板子性能用没到极致**。这块没人框住，是团队要自己拿主意的重头。本文提出量化标尺 + 对标主流差距 + 极致路线。

## 一、效果定量量化 · 四维指标体系（每项都要出数字）
### 1. 检测效果（对 OpenCV MOG2/ViBe 黄金参考）
准确率 / 召回率 / F1、误检率（空场景虚警）、漏检率（远处/暗/静止）、一物多框率、目标计数准确率、ID 一致性（MOTA/MOTP）。
### 2. 性能
分辨率（现 1280×720）、帧率（实测 27-30fps）、并发目标数（16）、端到端延迟、多目标稳定性。
### 3. 资源/能效
LUT（17475）、BRAM（45%）、DSP（1）、每帧功耗 / 能效（pJ/pixel、J/img）。
### 4. 板子利用度
PS/PL/DDR/VDMA/DSP 利用率（现状 PS/DDR/VDMA = 0%）、时钟健壮性（板载 125MHz 靠 PHY、网线坑）。

## 二、对标主流 / 大佬（诚实标差距）
| 维度 | 我们现状 | 主流 / 大佬 | 差距 / 判断 |
|---|---|---|---|
| 算法层级 | L0 帧间差分 | L2 GMM/ViBe（学术工业主流） | 差一整层；PYNQ-Z2 BRAM 4.9Mb 放不下标准 ViBe(46Mb)，**须上 DDR 才追得上** |
| 架构 | 纯 PL，PS/DDR/VDMA 0% | VDMA+DDR+异构（同行调研 3/4 用） | "小打小闹"的批评在此有硬数据；须上 PS 才达标 |
| 分辨率 | 1280×720 | 同行多 640×480 | **我们 2.7-4×，加分** |
| 目标数 | 16 并发 | 同行多单框 | **我们加分** |
| 实现 | 纯 Verilog | 多 HLS | 贴"FPGA 设计"评分导向，加分 |
| 巨人基准 | — | IEEE TVLSI GMM(Virtex-6 1080p@91fps/3%逻辑)、HotEdgeVideo'19(ZCU102 能效比 RTX2080 高6.1×)、AMD XAPP(Zynq-7000 LK 光流) | 看齐目标，非短期可达 |

## 三、性能开发到极致的路线
- **短期（本届保底，1-3 天）**：帧差 → 均值背景建模（`MODE_BG=1`，零 BRAM 增量）+ 形态学改闭运算 + 降 MIN_CNT/THRESH + **建 OpenCV 黄金参考定量比对**（把"效果"变成数字，正对"以 OpenCV 比对"评分项）。
- **中期（架构级，要动 PS/DDR）**：上 PS/VDMA/DDR 异构 → 解锁 ViBe/GMM（46Mb 需 DDR）+ PS 跑黄金参考 → 算法从 L0 跳 L2。
- **极致对标**：在 PYNQ-Z2 资源约束下，把"背景建模"思想落地到极致（BRAM 账逼出的工程档，不是照抄 ViBe）。

## 四、结论
效果量化 + 性能对标是评委重头，流程验收只是及格线。路线：**短期把"效果数字 + 背景建模"做实（保底）→ 中期上 DDR 追 L2（加分）→ 全程对标巨人基准量化差距**。建议把本文的四维指标表作为后续所有优化/汇报的度量衡。
