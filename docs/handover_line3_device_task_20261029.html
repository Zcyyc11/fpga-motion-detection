一句话目标

把"背景帧缓冲"从 BRAM 搬到外部 DDR，解开 BRAM 枷锁（现在 1 帧就占 45%，放不下真 ViBe）；顺带用 PS FCLK 替掉 PHY 125MHz，把"不插网线就黑屏"这个坑彻底治死。

你要搭的 BD（Block Design）

大块谁怎么连
Zynq PS7主控FCLK_CLK0→PL 像素时钟 / FCLK_CLK1→AXI；GP0→AXI-Lite 桥→md_pipeline 的 ps_* 钩子
AXI VDMA内存搬运S2MM 把进帧写 DDR、MM2S 把背景样本读回；走 HP0 高带宽口
DDR3 控制器PS 内背景模型 + 帧缓冲 都住这

接线钩子（已经给你留好了，不用改顶层架构）

src/rtl/md_pipeline.v 已有 6 位地址的 ps_en / ps_we / ps_addr / ps_wdata / ps_rdata + clk_axi，当前悬空（INCLUDE_PS=0）——接上 AXI-Lite 桥就通。MODE_BG 参数切帧差/背景建模。

踩雷清单（前期排过，别再踩）

  • GP0 不接时钟 → BD 报 41-758；
  • FCLK 从 PS 引出到顶层再用 → DRC NSTD-1 / UCIO-1 拒 bitgen，应在 BD 内直连；
  • VDMA 必须走 HP0（不是 GP），背景模型大流量要带宽；
  • dvi2rgb 的 RefClk 仍要 200MHz 独立 MMCM，别蹭像素时钟 VCO。

验收门（Tier2 算"整完"的硬判据）

  1. 拔掉 RJ45 网线 → 屏仍出图（FCLK 生效，时钟坑根治）；
  2. VDMA 通：S2MM 写 DDR ≥ 60fps@720p 无丢帧，MM2S 回读背景样本正确；
  3. BRAM 占用回落 < 10%（背景模型真在 DDR 了）；
  4. 出 bit + 上板测，回传 bit SHA / HDMI 截图 / 验收表。
不越界： 算法内核（ViBe/GMM）是徐的活，你只需把"背景样本存取走 DDR"的通路 + 检测通路搭好，把接口给徐。改接口前群里确认。
