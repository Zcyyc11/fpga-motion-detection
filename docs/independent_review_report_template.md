## 发现

每项发现写：严重程度、具体文件与行号、需求依据、最小复现命令、实际与应有行为、影响、建议，以及是否独立复现。没有发现的问题也说明检查范围，不用“没有发现”推断不存在。

## 对作者结论的核对

逐项说明认可、反驳或证据不足；另列作者没有提及的新问题。明确模型与被测实现是否共享假设，既有测试是否可能漏检。

## 清理、复现和 GitHub

记录干净检出的尝试、缺失依赖、保留证据与备份检查。列出本地及远程 SHA、分支是否存在、是否包含受测提交、main 是否合并、是否有真实他人审核；每一项独立判定。

## 给原 Codex 的反馈

列出需要它处理或解释的事项、所需证据及复核方法。注明哪些必须等数据、板卡或团队确认。最终判定由本次证据决定，不预填通过或失败。
