## 设计

保留旧 JSONL/TCP 工具。新增纯 Python 二进制解析模块、串口/文件接收入口、独立
构造测试。串口固定 115200-8N1、无流控；三包长度 5/14/8，小端、累加校验。
逐字节扫描重同步；不猜未定义 FLAGS；所有坐标须在 640×360 且端点有序。
每个新帧头关闭上一帧，按 OBJ_CNT 核对数量；事件即时输出并归属对应帧。
16 位回卷可接受，缺帧/重复/倒序单独记错；复位后开始新采集，避免猜测回卷。
结束时保存已收完整帧，但没有事件数/结束包，不能证明最后一帧事件完整性。

原始字节、包、帧、事件和异常分别落盘；输出目录必须全新，默认保存前 100 张图，
其余帧继续记录，限制时长/字节/帧数。串口断开、Ctrl+C 和截断保留已有证据并非零退出。
数据来源由用户声明，只区分 simulated / board-unverified，程序不能认证实机来源。
画框使用含端点坐标映射 x2→2*x2+1；坐标画布不冒充同步视频。

不改 RTL/顶层/协议/算法/历史成绩。真实样本与实际 COM 端口由线二提供。
不将桥尚未合 main 误写成线三阻塞；不合并 main，不删除文件。
