## 四、UART 回传协议 v0.2（定稿）

### 4.1 链路参数

- UART **115200-8N1**，无流控，板端 TX → 电脑 RX。
- 小端序；校验 = 包内字节（含 MAGIC）累加和低 8 位；校验失败丢包、扫 MAGIC 重同步。
- 数据流：帧头包先排队（下一帧 tick 时才知道本帧目标数），目标/事件包随到随入 FIFO；PC 端看到数据滞后一帧（与 bbox 帧滞后同口径，正常）。

### 4.2 包结构（三种包，接收端按 MAGIC 分流）

| 包 | MAGIC | 长度 | 内容 |
|---|---|---|---|
| 帧头包 | **0x5A** | 5B | MAGIC + 帧号(2) + OBJ_CNT + CHK |
| 目标包 | **0xA5** | 14B | MAGIC + 帧号(2) + 目标ID + X1/Y1/X2/Y2(各2) + FLAGS + CHK |
| 事件包 | **0xC3** | 8B | MAGIC + 帧号(2) + ID + TYPE + 中心X(2) + CHK |

- **事件包 0xC3（本版线一确认）**：告警事件独立成包；TYPE **1=越界、2=停留**；有告警才发，电脑端实时收到，无需轮询。
- 坐标域：**640×360 大像素**，右下含端点，还原原图坐标 ×2。
- OBJ_CNT 范围 0..16；FIFO 满丢弃并置 STATUS bit31（丢包粘存）。

### 4.3 带宽论证（报告素材）

- 115200-8N1 上限 ≈ 11.5 KB/s。
- 实际：帧头 5B + 目标 14B×N，单目标 16 目标全满 ≈ 3 KB/s，余量充足。
- 结论：UART 用于"结果回传"带宽够、成本低——这就是软硬件划分依据之一。

## 五、AXI-Lite 寄存器接口（线一方案）

### 5.1 寄存器表（0x00–0x34）

| 地址 | 名称 | 属性 | 说明 |
|---|---|---|---|
| 0x00 | THRESH | RW | 帧差阈值（16bit） |
| 0x04 | THRESH_REL | RW | 相对阈值 |
| 0x08 | ALPHA_SHIFT | RW | 背景建模系数 |
| 0x0C | LINE_X | RW | 警戒线 X（默认 640） |
| 0x10 | DWELL | RW | 停留判定时长 |
| 0x14 | ENABLE | RW | 使能 |
| 0x18 | STATUS | RO(部分) | bit31=丢包粘存（写清）；**bit1=告警帧级粘存（选 A）**；低 31 位=i_status |
| 0x1C–0x34 | BBOX_* ×7 | RO | 快照：X1(0x1C)/Y1(0x20)/X2(0x24)/Y2(0x28)/CNT(0x2C)/VALID(0x30)/FRAME(0x34) |

### 5.2 设计要点（报告素材）

- **BBOX 快照 + 两级握手 CDC**：像素钟域帧边界连同 frame_idx 同拍锁存 → 两级握手进 AXI 钟域 → 防"读一半数据变"（撕裂）。
- **STATUS bit1 = 帧级粘存（线一拍板选 A）**：单拍脉冲 PS 轮询读不到，帧级粘存 = "上一帧有无告警"，与 BBOX_FRAME 同源可交叉校验。
- **ps_addr 加宽 [5:0]**：0x20 后地址不被截断（线二 10/12 完成）。

### 5.3 双通道关系（写清楚，避免打架）

| 通道 | 形态 | 用途 | 实时性 |
|---|---|---|---|
| UART（乙） | 事件/目标流 | 电脑端实时收目标+告警（推送） | 帧级实时 |
| AXI-Lite（甲） | 寄存器查询 | PS 侧查询快照、参数控制（拉取） | 查询时一致 |

> 关系：**UART 管"推"（实时事件），AXI 管"拉"（快照查询）**，数据同源（同一 bbox/同一帧边界），不是两套结果。告警双出口：事件包 0xC3 实时推送 + STATUS bit1 帧级粘存可校验。

## 七、报告"接口设计"章节素材清单（线三写报告时用）

1. 为什么双通道：UART 实时推送 vs AXI 查询快照，各自带宽/时延/复杂度论证（§4.3 + §5.3）。
2. 为什么事件包独立成包：对比"塞进目标包 FLAGS"——电脑端免轮询、告警不丢、可扩展（TYPE 预留 3+）。
3. 为什么 AXI 快照用两级握手 CDC：对比"直接跨域读"——防撕裂，写明失效条件与替代方案。
4. 为什么 STATUS bit1 用帧级粘存：对比"单拍脉冲直连"——PS 轮询读不到；对比"写清 sticky"——帧级粘存与 BBOX_FRAME 可交叉校验。
5. 带宽实测计划：上板后抓真实报文，统计实际 B/s 与丢包率，与 §4.3 理论值对照。
