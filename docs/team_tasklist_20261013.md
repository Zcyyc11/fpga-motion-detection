## 两遍对照（2026-10-13 17:5x 改判，防两版打架）

- **第一遍（真达标）**：徐一夫**完整串行版**（16 目标 + LUT<50%）——实现于提交链 c0e13d3→0d40bd7（已恢复为分支 line2/serial-wip），资源达标(OOC LUT 19,048/35.8%)；但功能从未通过独立复核(f7f4134: 16目标满配仅出9框、串根合并、面积不守恒,根因FIFO静默丢样)，故"真达标"说法不实。并非 stash 实现（reflog 从无 stash 记录），也未作为达标版并入 main。
- **应急基线**：8 目标版（LUT 11,913/22.39%）——实际已于 74e6e04 并入 main（与本条"不并入"说法矛盾），现 main 持此 8×4 版作保交付基线；16 目标达标版从未并入。
- **第二遍**：孙伟博整体优化接力 → 不赶 deadline，达标后对照选优/合并
- **分支纪律**：徐一夫 `line2/multibbox-pipeline`、孙伟博 `line3/verify-cleanup`→`line3/opt-pass2`、顺序进行不抢文件；验收标准通用（`handoff_code_fixes_20261013.md` 第五节，第一条 16 目标满配不可豁免）
