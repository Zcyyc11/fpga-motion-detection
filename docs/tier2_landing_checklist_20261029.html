定位：阶段二是“拿成熟开源管线接上”，不是从零造。PL 现状（帧差/红框/HDMI/UART）不动，新增 VDMA+DDR 把背景模型放外部 DDR，解锁真 ViBe/GMM。设备码（RTL/综合/上板）归伟博，本清单只给“接谁、接哪、接口怎么对”。

二、接口怎么对（关键映射）

  • PL→DDR：现有视频管线输出帧，经 VDMA S2MM 写 DDR（HP0 端口），不要手撸 AXI。
  • 背景模型：ViBe/GMM 样本集（标准 N=20 ≈ 46Mb）放 DDR，不再占 BRAM（BRAM 仅 4.9Mb，纯 PL 放不下是共性约束）。
  • DDR→显示：VDMA MM2S 读回处理后的帧，接现有 HDMI OUT。
  • PS 角色：用 PYNQ Python 驱动 VDMA + 在线调参；PS FCLK 已是系统时钟（阶段一已治时钟坑）。

三、风险点（伟博综合/上板时盯）

风险说明
DDR 带宽720p@60fps 读写带宽，确认 HP 端口位宽/突发够用
VDMA 握手S2MM/MM2S 同步、framecount 缓冲，避免撕裂/丢帧
综合资源加 VDMA+DDR 后的 LUT/ BRAM/ DSP 占用，留余量
算法正确性ViBe/GMM 在软件/软逻辑实现，先离线对齐再上板

四、验收标准（上板过这几条才算 Tier2 收口）

  • 上板跑通：VDMA+DDR 链路稳定，无 DDR 错。
  • 效果提升：相比纯 PL 帧差，真背景建模在静止背景/弱小目标上明显更稳（肉眼 + 截图对比）。
  • 资源报告：综合后资源占用给出，证明未超限。
  • 材料回填：Tier2 验收记录 + 对比截图进交付包，更新设计报告“实测”章节。
