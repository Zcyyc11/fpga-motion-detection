# 入门：30 分钟自己跑出结果

> 这份文档的目标只有一个：**你 clone 下来之后，半小时内能自己跑出东西，不用问任何人。**
> 跑通了，你就有资格接活；跑不通，把卡住的那一步发群里。

---

## 第一步：拿到代码（5 分钟）

```bash
git clone https://github.com/Zcyyc11/fpga-motion-detection.git
cd fpga-motion-detection
```

**不需要的东西**：Vivado（跑仿真和数据部分不需要）、板子（这一轮先不用）。

---

## 第二步：装 Python 环境（10 分钟）

我们用的是 **Python 虚拟环境**，不要装到系统 Python 里。

```bash
python -m venv .venv
.venv\Scripts\activate
pip install numpy opencv-python
```

验证：

```bash
python -c "import numpy, cv2; print('OK', numpy.__version__, cv2.__version__)"
```

**看到 `OK` 就过了。**

---

## 第三步：跑算法实验台（15 分钟）

这是**最值得先跑**的一个，因为它不碰板子、跑坏了也没事。

```bash
cd src/ps
python algo_lab.py --set r11 --seq baseline/pedestrians
```

你会看到一张表，每个变体一行，最后一列是分数。

**这张表就是我们的成绩单。** 当前冠军 `V43`，官方口径 **0.737**。

### 想自己改一个参数试试？

打开 `algo_lab.py`，找到这一行（第 370 行附近）：

```python
V43 = ("V43 V38+全局补偿 R2/抽样4", _dual(1.0 / 32, 0.0, thresh_rel=0.15, thresh_floor=25,
                                     rel_on="local", adapt_rel=(0.12, 0.30, 0.05, 0.30),
                                     gshift=2, gshift_step=4))
```

- `thresh_rel=0.15` → 阈值比例，改大更严格、改小更敏感
- `gshift=2` → 全局运动补偿的搜索半径
- `gshift_step=4` → 补偿的抽样密度（注意：这个值**越小编得越准**，4 比 8 好）

改完保存，再跑一遍上面的命令，看分数变没变。

---

## ★ 一条你必须知道的纪律

**只跑 1~2 条序列的分数是不可信的。**

我们有血的教训：有个变体在 3 条快测里表现最好，一跑全量 12 条直接崩到 0.554。

所以：

```bash
# 快速试探（只用来筛掉明显不行的）
python algo_lab.py --set r11 --seq baseline/pedestrians

# ★ 下结论必须跑全量（12 条，约 25 分钟）
python cdnet_official.py --set r11 --seq all
```

**任何"我改的这个更好"的说法，必须拿全量数字说话。**

## 常用命令速查

| 想干什么 | 命令 |
|---|---|
| 跑变体集（快） | `python algo_lab.py --set r11 --seq baseline/pedestrians` |

## ★ CDnet 数据集怎么放（换机器必看）

跑 `algo_lab.py` / `cdnet_official.py` 需要 **CDnet2014** 数据集。

**它不在本仓库里** —— 约 **0.96 GB / 5.2 万个文件**，GitHub 单文件上限 100 MB，放不进来。需要自己从 CDnet 官网下载。

**放在哪 / 怎么指过去**：代码会先找环境变量，再退回本机默认路径。

```bat
:: Windows
set MOTION_CDNET_ROOT=E:\path\to\cdnet2014
```

```bash
# Linux
export MOTION_CDNET_ROOT=/path/to/cdnet2014
```

不设就用默认的 `D:\FPGA\datasets\cdnet2014`。

**怎么确认放对了**：

```bat
python algo_lab.py --list
```

| 输出 | 意思 |
|---|---|
| `可用序列 (12)` | ✅ 放对了 |
| `可用序列 (0)` + 后面一串提示 | ❌ 没找到。**脚本会直接告诉你当前找的是哪儿、怎么修** |

### 没有数据集也能干的活

| 能干 | 命令 |
|---|---|
| **跟踪 + 告警**（用仓库自带的合成考场 `data/golden/track_cross.avi`） | `python multi_track.py --source algo --alarm --line-x 640` |
| **RTL 仿真**（不需要任何数据集） | `python build\scripts\run_sim.py` |

## 卡住了怎么办

1. **先看报错最后一行**，那通常是真原因
2. 报错提到 `ModuleNotFoundError` → 你的虚拟环境没激活，回去第二步
3. 报错提到文件找不到 → 确认你在 `src/ps` 目录下跑
4. 还是不行 → 把**完整报错 + 你跑的命令**贴群里，别只发「跑不了」
