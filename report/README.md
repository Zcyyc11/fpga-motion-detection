# report/ — 设计报告与大模型协作记录

| 子目录 | 放什么 |
|---|---|
| （本目录） | **设计报告**：选题背景与创新点 / 设计原理与功能框图 / 软硬件划分依据与接口设计 / **优化前后性能与资源对比表** / 复现说明 / 判断依据 |
| `figures/` | 报告插图（功能框图、流水线图、资源/时序对比图、HDMI 输出截图） |
| `llm_log/` | **大模型协作记录**（提示词、模型回答、自我纠错轨迹） |

**写作纪律**：
1. 报告要写**判断依据**，不能只呈现结果 —— "为什么这么选、代价是什么、还有哪些备选被否掉"。
2. **优化前后对比表**必须给基线（先测基线，再谈优化），禁止先写目标后凑数据。
   - 表头建议：指标 / 基线 / 目标 / 对比对象
3. 每张图都要能回答"它证明了什么"，只作装饰的图删掉。
