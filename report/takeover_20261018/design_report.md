# FPGA运动目标检测资源重构与验证报告（板测前版本）

日期：2026-10-18。平台：PYNQ-Z2 / XC7Z020-1CLG400C。当前成果为板测候选，不宣称比赛验收完成。

## 问题与方案

作品以纯PL流水线完成720p灰度输入、2×2求和降采样、帧差/背景建模、阈值、形态学、多框、跟踪、告警及UART回传。核心重构将每帧可以串行完成的计算从单周期展开改为分拍复用，保护原协议与命名端口。

track以双银行收集和串行贪心匹配代替16×16组合展开，保持活ID唯一、自然回绕和生命周期。UART采用三银行不可变帧记录、独立目标/事件存储和逐字节打包，过载丢整帧。multi_bbox使用同步BRAM输入队列、规范化标签别名、65535饱和计数及串行帧末收集。AXI独立接收AW/W并推迟B响应到后端采样之后。line_buf独立同步写保持仿真等价。

## 协作与自我纠错

协作输入包含接手材料、冻结接口、旧资源报告和失败用例。主要纠错包括：AW/W握手拆分与B响应过早；bbox标签复用别名、65536计数回绕；串行输出下标位宽导致X；UART银行原子丢帧；默认Python环境缺依赖不能算通过。红测/编译失败与后续绿测保留在隔离证据目录。

可复用方法是：先固定需求与源SHA，保留失败输入，将一帧吞吐预算写成周期上界，再分模块OOC、独立参考核对，最后完整物理构建与实机证据。仓内skill已有工具包，本轮补充技能说明。本文是过程摘要，不能冒充完整原始提示词/回答；完整对话导出仍是提交待办。

## 复现与剩余项

使用个人分支 `codex/full16-resource-20261017`，参考release_manifest和frozen_manifest。设置MOTION_IP_REPO为Digilent vivado-library，MOTION_BUILD_DIR为新的纯英文空输出目录，调用 `build/scripts/build_vivado.tcl -tclargs 0 1 all`。禁止用历史bit或OOC报告替代此次报告。第三方IP不随源码归档复制，需按来源取得，具体版本见交付manifest。
