# sim/ — 仿真与验证

**职责**：证明功能正确性，并留下**可复核的证据**。

| 子目录 | 放什么 |
|---|---|
| `tb/` | testbench（每个 RTL 模块一个，命名与被测模块一致） |
| `wave/` | 波形配置（`.wcfg`）与仿真输出图（逐模块输入/输出对照） |

**纪律**：
1. 每个模块提交前**必须有** testbench 与仿真结果，不接受"没仿真直接上板"。
2. 仿真结果要能回答"这一级流水线的输入与输出分别长什么样" —— 建议按级输出图像，一图对应一级。
3. 帧边界（`tvalid`/`tready` 握手、`tlast`/`tuser` 帧同步）必须专门构造用例验证，这是最容易出错的地方。
