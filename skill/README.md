# 技能包（skill/）

> 官方要求：须含 `README.md` 说明每一项的**适用范围、使用方法与失效条件**。
> 评价标准是**可复用性** —— 一支陌生队伍拿到该目录，能否直接用在自己的题目上。

## 技能清单

| # | 名称 | 形态 | 通用性 | 状态 |
|---|---|---|---|---|
| 1 | Overlay 加载与校验流程 | 校验脚本 / 踩坑清单 | ✅ 任何 PYNQ 项目 | ⬜ 待沉淀 |
| 2 | VDMA 搬运与缓存一致性处理封装 | 案例模板 / 踩坑清单 | ✅ 任何视频流项目 | ⬜ 待沉淀 |
| 3 | 黄金参考逐像素比对脚本 | 校验脚本 | ✅ 任何图像处理项目 | ⬜ 待沉淀 |
| 4 | 资源与时序数据自动采集并生成报告表 | 校验脚本 | ✅ 任何 FPGA 项目 | ⬜ 待沉淀 |
| 5 | 视频流水线行缓冲 / 时序约束踩坑清单 | 踩坑清单 | ✅ 任何视频处理项目 | ⬜ 待沉淀 |

> **通用 PYNQ Skill 单独加分**：面向 PYNQ 框架且**不与本队题目绑定**（换题目、换板卡仍可用）的 Skill 另行加分。
> 因此上表每一项都要尽量剥离本题目特有条件，写成"任何 PYNQ 项目都能用"的形式。
