# src/ — 设计源码

按实现方式分三个子目录。**核心算法必须落在 PL**（PS 侧 Python 只作黄金参考与对照，不可替代 FPGA 设计）。

| 子目录 | 放什么 | 说明 |
|---|---|---|
| `rtl/` | 自研 Verilog 模块 | 像素流水线：灰度化 / 帧差 / 阈值 / 形态学 / 质心 / 框叠加；行缓存、FIFO、跨时钟域处理 |
| `hls/` | HLS 算子（如有） | 仅在 RTL 不划算时使用；须说明为何不手写 RTL |
| `ps/` | PS 侧软件 | PYNQ Python 脚本与 notebook：加载 overlay、驱动 VDMA、读取质心结果、黄金参考比对 |
