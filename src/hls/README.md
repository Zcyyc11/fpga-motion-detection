# src/hls/ — HLS 算子（按需）

**当前为空。** 本工程以**手写 RTL** 为实现主线，符合初级组"逻辑设计 / 状态机 / 时序约束 / 接口协议"四项考察侧重。

**只有在下列情况才引入 HLS**（引入时必须在本目录 README 写明**为什么手写 RTL 不划算**）：

| 情形 | 说明 |
|---|---|
| 算子算术密集且 RTL 实现代价过高 | 如大窗口滤波、复杂归一化 |
| 官方提供的加速库已满足需求 | 如 `xv2.dilate()` 形态学膨胀，避免重复造轮子 |
| 需要与现有 HLS IP 对接 | 集成既有 IP 的粘合逻辑 |

> ⚠️ **红线**：不得把算法主体整体推给现成 IP 或 PS 侧，导致初级组四个考察点没有硬内容。
