# src/ps/ — PS 侧对照与验证脚本

**定位：本目录不是作品实现。** 作品的功能主体在 `src/rtl/`（PL 内纯 RTL 流水线）。
这里的东西只有一个用途 —— **当标尺、当考场、当证据**：把 PL 算得对不对、值多少，量成能写进报告的数字。

| 文件 | 作用 |
|---|---|
| `rtl_golden.py` | **硬件模型参考**：照抄 RTL 的整数运算（2×2 和域、阈值 70、3×3 方核、零扩展边界），逐帧产出包围盒，与 xsim 导出的 `sim/wave/bbox_rtl.csv` **逐帧逐字段比对**，判据是必须报「完全一致」。**它回答的是"仿真跑出来的那些数，是不是真的算对了"。** |
| `golden_ref.py` | **算法黄金参考**：全分辨率 720p、阈值 25、cv2 椭圆核。三种差分模式（framediff / gap2 / compensated），输出**运动区域的外接框中心**，用来量化「帧差法比真值偏多少」。 |
| `cdnet_demo.py` | 在 **CDnet 2014** 真实素材上跑帧差法，与人工真值逐像素比对（精确率 / 召回率 / F1 + 三方对比图）。 |
| `algo_ab.py` | **受控 A-B 对照**：照抄参考作品 #1 的全部做法（2×2 压缩、阈值 70、核 3），**只换第 2 步**（帧差 ↔ 背景建模），输出两组 F1 差值与 α 扫描。 |
| `five_steps.py` | 把「五步链只换第 2 步」画成逐级中间图对照（上排帧差 / 下排背景）。 |
| `requirements.txt` | PC 开发期依赖清单（opencv 锁 4.x，与 PYNQ 镜像同代）。**板卡镜像自带 numpy/opencv，上板不必再装。** |

> ⚠️ **口径纪律（别混着引用）**：`golden_ref.py` 输出的是**外接框中心**；
> `algo_ab.py` / `five_steps.py` 第 5 步用的是**连通域真质心**。
> 两者在单个矩形目标上数值恰好接近，但概念不同、多目标时**不等价**，报告里同时出现时必须写明各指哪个。
> 另外：**本设计不经过 PS 加载 overlay 跑检测**，所以本目录既没有 overlay 加载脚本，也没有上板主流程脚本 —— 这是设计如此，不是缺件。

> ⚠️ 黄金参考**只用于验证**，不构成作品实现。

## 黄金参考的三种差分模式

`golden_ref.py` 不只是"跑一条算法链"，它把**帧差法外接框中心的系统偏差**做成了可量化的对照。
物体每帧位移 d 像素时，帧差得到的是两条宽约 d 的边缘细带，由此产生偏差：

| 模式 | 做法 | 偏差 | 帧缓存代价 |
|---|---|---|---|
| `framediff` | `\|I(t)−I(t−1)\|` 取合并外接框中心 | **恒偏 −d/2** | 1 个 |
| `gap2` | `\|I(t+1)−I(t−1)\|` 取合并外接框中心 | 无偏（前后对称抵消） | **2 个** |
| `compensated` | 1 帧差分 + 用细带宽度估 d 再补偿 ±d/2 | 无偏 | 1 个 |

**这个取舍正是评分项「性能与资源优化」要的东西**：`gap2` 准但帧缓存翻倍（DDR 带宽与容量都要加），
`compensated` 同样准，只多几次加减法。

### 正式比对在哪里跑

黄金参考**要跑在板卡 PS 端**，用 PYNQ 镜像自带的 numpy / opencv ——
同一块板、同一段输入、同一分辨率，比对才公平。PC 上跑只作开发期验证与偏差量化。

## 两类测试素材，分工不同（别混）

| 素材 | 干什么用 | 能回答什么 |
|---|---|---|
| 合成片段 `data/golden/synth_720p.avi` | **尺子**：只有我们知道每帧标准答案 | "偏差多少像素"——**几何精度**（定量） |
| 真实素材 CDnet 2014（仓外） | **考场**：真实噪声 / 光照 / 动态背景 | "到底能不能用"——**失效模式**（定量+定性） |

两者不可互相替代：合成片段干净得测不出失效，真实素材没有精确的几何答案。

### `cdnet_demo.py` 的两条纪律（数据集的规矩）

1. **只用 `temporalROI.txt` 给定区间内的帧** —— 区间外是预热/收尾，画面还没动，
   算进去等于刷分。脚本已自动读取并遵守。
2. **真值标签里只有 `0`（静态）与 `255`（运动）参与计分**；
   `50`（硬阴影）/ `85`（ROI 外）/ `170`（不确定运动）一律排除
   —— 阴影和"说不清"的像素不该拿来罚算法。

用法：

```bash
rem 先设好数据集根目录（或直接用 --seq 给序列的完整路径）
set CDNET_ROOT=<你放数据集的目录>/cdnet2014
python cdnet_demo.py --seq %CDNET_ROOT%\baseline\pedestrians
python cdnet_demo.py --seq %CDNET_ROOT%\dynamicBackground\canoe
python algo_ab.py --seq both --sweep      # 帧差 vs 背景建模的受控对照 + α 扫描
```

> 素材说明见 `data/captures/README.md`（数据集根目录下的 `README.md` 内含校验值 / 目录结构 / 真值标签含义 / 全部 53 段清单 / 引用要求）。
