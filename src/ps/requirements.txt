# PS 侧（黄金参考）运行时依赖
#
# 用途：PC 开发期验证  /  板卡 PS 端正式对照
#
# 说明
#   - 板卡 PYNQ v3.1.1 镜像**自带** numpy 与 opencv，上板时不必再装；
#     正式对照请使用镜像自带版本（同一块板、同一段输入才叫公平比对）。
#     本清单描述的是 PC 开发期环境。
#   - opencv 刻意锁 4.x：与 PYNQ 镜像（2024 年版本）同代，
#     避免跨大版本导致算法行为出现说不清的差异。
#   - ★ 版本写成**区间**而不是 ==：队友机器上装的是
#       numpy 2.1.3 / opencv-python 4.13.0 / matplotlib 3.10.0，
#     和本机（2.2.6 / 4.12.0.88 / 3.10.8）不一样。写死 == 会逼着别人
#     装/卸一遍，而这两套组合我们都实测过，都能跑。
#     真要锁死某一套，自己 pip freeze 一份，别改这个文件。
#   - 安装：pip install -r requirements.txt
#   - 开发 venv 建在仓库之外（不入库），例如在仓库同级建一个 venv 目录

# --- 黄金参考本身 ---
numpy>=2.1,<3
opencv-python>=4.10,<5

# 中文标签需要系统里有 Microsoft YaHei / SimHei 字体（Windows 自带）。
matplotlib>=3.8,<4

imageio-ffmpeg>=0.4,<1
